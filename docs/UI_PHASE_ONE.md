# 第一阶段 UI 迭代

11 月 5 日追加成员反馈优化，详见[反馈处理记录](UI_FEEDBACK_2026-11-05.md)。下文保留 11 月 3 日首轮实施记录。

分支：`codex/ui-phase-one`。依据本次产品评审实施，代码整理与主线同步见[版本对齐记录](RELEASE_ALIGNMENT_2026-11-06.md)。

## 范围

- 沿用现有松绿品牌、TDesign 基础控件、主题 Token 与听 / 查 / 录 / 我导航。
- 首页压缩重复引导，录音卡按地区、内容、大意、播放、贡献者、参与操作组织；播放按钮保留真实的停止行为。
- 搜索显示当前地区与筛选摘要；历史和热门内容只在初始状态出现；空结果可以清除筛选并保留关键词。
- 词条详情顺序为释义摘要、录音、分义与写法、专业读音、证据与参与操作。
- 录音明确区分“提交并公开”与“保存草稿”，提前展示 15 秒限制；保留既有上传、草稿恢复、登录恢复及错误处理。
- 修正 TDesign 圆形录音按钮的尺寸优先级，避免被组件默认宽度挤成椭圆；减少动态效果时停用录音波形循环动画。
- 个人中心压缩头像，区分已有贡献概览与真实空态。

## 边界

本轮不更改 API、权限、公开规则、录音时长、身份模型、平台能力和播放生命周期。工作区原有的录音可见性改动继续保留。

- 既有搜索与详情层级、上传失败保留草稿、页面壳响应式回归。
