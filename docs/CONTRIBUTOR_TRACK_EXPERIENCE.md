# 乡声共创计划
## Dialect Experience Contributor Guide

> 让方言本身变得好用、好玩、值得表达、值得分享；保护发生在使用之后。

## 1. 负责什么

乡声共创计划负责乡声集盒的“用户价值侧”，核心不是增加页面，而是回答：

- 普通人为什么愿意第二次打开？
- 为什么愿意把一段乡音发给朋友？
- 为什么愿意顺手录一句自己的说法？
- 为什么贡献之后愿意继续回来？

核心飞轮：

```text
听 / 查
  ↓
分享 / 比较
  ↓
“你们那里怎么说？”
  ↓
录音 / 确认 / 补充
  ↓
更多高质量资料
  ↓
更好用、更好玩的内容
```

## 2. 最小贡献门槛

普通母语者不需要先学 IPA、正字、EntrySense 或 Evidence。

一个最小有效贡献只要求：

```text
录音
+ 这句话 / 口音来自哪里（最小语言背景 / 来源信息）
+ 大意
```

专业字段渐进展开。当前物理位置 / GPS 只能作为辅助 geo hint，不自动等同于方言或口音归属。

## 3. 当前优先原则

- 分享优先于复制一个封闭社交平台；
- 贡献之后要展示“现在处于什么状态、后来如何被整理、产生了什么知识影响”；
- 主题只能改变氛围，不能改变控件语义、可读性与危险动作识别；
- 兴化语记保留品牌，迁为莆仙方言站，不继续发展第二套前后端；
- 轻量整理尽量在乡声集盒完成，完整批量校勘才进入万语校坊。

## 4. AI-native

允许使用 Codex、Claude Code、Cursor、Copilot、Pi 等工具，但 contributor 本人必须：

1. 理解 Issue；
2. 先调查后实现；
3. 按风险检查关键 diff、contract、权限、数据变更和测试断言；
4. 自己运行与风险匹配的测试/构建；
5. 自己走关键用户旅程或检查数据结果；
6. 如实记录 `Not manually verified`；
7. 能解释为什么这样做、最可能如何失败。

详见 [AI-native Contributor 指南](AI_NATIVE_CONTRIBUTION.md)。

## 5. 工作包

不按“首页负责人 / 登录负责人”永久分模块。默认：

- 1 个 Primary（S/M）
- 1 个 Secondary（XS/S）

Size 看判断、风险、验证与集成成本，不看 Agent 写代码用了多久。

## 6. Definition of Done

一个 Experience 任务至少回答：

1. 用户为什么到这里？
2. 一眼能否识别核心对象？
3. 最重要动作是否明确？
4. 加载 / 空 / 错误 / 成功是否完整？
5. H5 / 小程序关键行为是否一致？
6. 主题是否破坏可读性？
7. 完成后是否自然进入下一步？
8. 可分享内容分享出去后是否仍然能理解？
9. 产生数据时，用户是否知道自己提交了什么？

## 7. 不主动扩大的内容

- 新主题家族；
- 复杂会员 / 权威积分；
- 大型活动后台；
- AI 自动生成最终词条；
- 没有用户价值假设的炫技交互。
