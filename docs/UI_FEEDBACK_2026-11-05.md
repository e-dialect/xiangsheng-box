# 2026-11-05 成员反馈 UI 迭代

执行分支：`codex/ui-phase-one`。反馈来源为成员提供的 `1029.txt`（电脑 Edge）及 `H5语料证据核查报告.md`（11 月 3 日线上只读核查）。线上与本地版本未证明一致，本文记录本地实现和模拟数据验证，不将历史反馈直接视为当前生产故障。

## 已处理

| 反馈 | 本轮处理 |
| --- | --- |
| 列表缺少授权说明、状态不清楚 | 新增共享 RecordingContext，卡片和详情展示相同的授权原文、可见性与记录状态；缺失值明确标为未提供或未补充 |
| 原始提交与整理结果混淆 | 原始大意明确标为“贡献者原始大意”；详情的“关联词条与整理内容”独立成区 |
| 录音介绍冗长、进度与草稿操作难找 | 精简介绍；常驻工具区放置草稿箱、保存草稿和录音／地区／大意三步进度 |
| 本地文件入口与录音按钮布局 | 改为“选择本地录音”，与圆形录音按钮并排；极窄屏改为纵向排列 |
| 步骤状态与补充信息不明确 | 步骤仅显示待填写／已完成；补充区改为“补充这段乡音的信息（选填）” |
| 成功提示长期驻留 | 草稿完整保存后短暂提示，页面不常驻成功文字；未保存修改及错误继续保留 |
| 上传完成反馈 | 沿用录音提交成功后“已公开为初稿，待核对”的反馈，不把文件上传成功当作录音创建成功 |
| 主方言说明重复、操作不对称 | 精简说明，桌面与移动视口下两操作等宽等高，长文案自然换行 |
| 层级返回不明显、帮助离按钮远 | 当前范围区增加返回上一级；帮助文案移至确认按钮附近；快捷区改为默认与最近使用 |
| 方言搜索占位较大 | 压缩头部和快捷区间距，弹层采用可收缩的滚动内容区，保留搜索与逐级浏览 |
| 个人中心重复录音入口、切换面板混乱 | 删除资料操作区的高亮录乡音按钮；改为录音／词条／义项数字概览，独立查看贡献履历 |
| 履历动作不准确 | “收听这段乡音”改为“查看录音详情”，保留原详情导航 |

## 数据依赖与后续方案

- **贡献搜索与聚合**：当前接口是最近活动摘要，不提供完整搜索与可靠的跨类型 Entry 分组信息。后续应由服务端按权限返回完整分页搜索，并提供明确的 Entry ID、贡献对象类型及目标 ID；按 Entry ID 聚合，不能按显示文字合并。可先提供“按词条查看／按时间查看”原型；本轮不把对最近活动的本地筛选称为完整搜索。
- **处理进度**：分别展示录音可见性、记录状态及关联词条状态，不按数量推算完成比例。需接口提供明确状态与关联对象后实施。
- **证据核查**：原始提交保存完整性、审核决定和时间、补证对象关联、正式发布记录与 ID 11 的限制生效范围仍需后台脱敏记录核对。
- **授权范围**：本轮原样展示已有授权文本，不从自由文本推断访问权限，也不将“公开可见”解释为审核通过或允许引用。分享入口继续遵循既有可见性规则。
