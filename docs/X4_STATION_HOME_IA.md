# 兴化语记莆仙站首页 IA 与内容边界

关联：[#428](https://github.com/e-dialect/xiangsheng-box/issues/428)，父项 [#424](https://github.com/e-dialect/xiangsheng-box/issues/424)。调查日期：2026-10-03；当前实现基线：`95aaeb6`。

本交付定义设计与验收依据。地方站是一层品牌、内容策展和导航上下文；查词、录音、播放、详情、账户继续使用乡声集盒通用能力。可点击的[视觉与交互原型](assets/x4/station-wireframe.html)、[浅色总览](assets/x4/station-wireframe.png)、[深色总览](assets/x4/station-visual-dark.png)及[手机预览](assets/x4/station-visual-mobile.png)使用明确标注的示例内容，不表示真实生产资料、音频或已上线功能。文件名保留 `station-wireframe`，方便已有链接继续访问；内容已从灰框低保真提升为接近产品的视觉稿。

## 1. 用户任务与首屏

老用户先认出“兴化语记”，再理解这里仍能查莆仙话、听真人乡音、留下自己的说法。新用户不需要先理解产品组织关系。

| 顺序 | 区块 | 用户看到的内容 | 动作及去向 |
| --- | --- | --- | --- |
| 1 | 品牌与范围 | “兴化语记”“乡声集盒 · 莆仙方言站”；当前浏览范围“莆仙方言” | 显式进入乡声集盒；调整浏览地区 |
| 2 | 查一句 | 品牌下方“想查哪个家乡词？”及搜索输入 | 进入通用搜索；浏览范围为可修改初值 |
| 3 | 本期内容 / Campaign | 一条与地方生活有关的真实活动或精选乡音 / 专题；只在内容已发布时显示 | 有 Campaign 时进入对应通用任务；尚未实现时只展示有证据的精选内容，不展示可点击的假任务 |
| 4 | 真人乡音 | 公开 Recording 卡：大意、语言背景 / 地区、来源摘要 | 卡内播放；进入 Recording 详情；再到关联 Entry |
| 5 | 留一句乡音 | “你们家怎么说？”及单一录音动作 | 进入通用录音页，用户确认语言背景、大意与授权 |
| 6 | 精选词条 | 公开 Entry 卡：写法、大意、地区及有无真人录音 | 进入 Entry 详情，听关联录音；资料不足时诚实说明 |
| 7 | 集盒 / 专题 | 已发布的地方主题与已有通用 Collection 引用 | 进入通用集盒；没有可用内容时隐藏，不填充假数据 |
| 8 | 历史项目与关于 | “找旧链接？”“历史文章与工具”“关于兴化语记” | 按 URL 映射表解释承接状态；有授权且仍可用的历史入口才可外链 |
| 固定 | 通用四入口 | 听 / 查 / 录 / 我 | 同一套导航、搜索、录音和账户；不额外建立地方账户 |

首页采用“本期地方内容 → 使用 → 贡献”的内容顺序，不把所有旧工具铺成主功能宫格。手机首屏保留品牌、一个内容主动作和查词入口；真人乡音及下方内容可滚动浏览。微信胶囊、安全区和底部导航留空间；桌面只增加阅读宽度，不改变任务顺序。

地方站本期内容与 SF-X-E1 的 Campaign Feed 共用活动模型。当前 #440 尚未完成的任务引擎、ASR/TTS、长辈代理等能力不在本设计中承诺可用；未来按 capability 状态接入。

## 2. 地方层与通用层边界

### 视觉基线

原型沿用现有产品 `frontend/src/styles/tokens.scss` 的松绿品牌色、纸色背景、明暗主题和 immersive 深绿壳；它是文档中的独立 HTML，Token 为调查时的快照，后续产品实现须直接使用公共 Token 与组件，不复制这里的 CSS。

- 品牌区使用现有深绿沉浸式氛围与少量金色细节，配合兴化语记文字标识；小“兴”字是原型装饰，非新商标或正式品牌替换。
- 录音卡参考 `EntryRecordingCard.vue` 的作者 / 地区 / 大意 / 转写 / 动作分层；通用详情参考 `PageShell.vue` 与仓库 `recording-light.png` 的来源头、白色卡片和回站路径。
- 字体沿用产品的中文 serif 标题与系统正文，控制边框、阴影、圆角和留白；桌面并排看站点与详情，手机点击后切换到对应页面，返回遵循视图栈。
- “落大雨 / 表示雨突然下得很大 / loh dua ho”直接复用 `frontend/tests/e2e/helpers/visualReviewFixture.js` 的视觉示例，不声称该测试素材是审核后的语言事实。波形、专题、账户和贡献反馈均为设计示意；不编造真实播放时长、用户统计或已完成贡献数。
- 原型提供深浅主题和五种页面状态。第二站切换时移除莆仙示例读音与归属，使用中性资料占位；来源站不成为语言事实。

| 能力 | 地方层负责 | 通用层负责 | 约束 |
| --- | --- | --- | --- |
| 品牌 | 兴化语记标题、关系说明、地方叙事 | 统一产品壳与导航 | 保留熟悉品牌，不另建后端 |
| 内容策展 | 指向公开 Entry / Recording / Collection 的精选引用与排序 | 实体、读音、证据、关联、播放、可见性 | profile 不复制对象；不自动判定正字或唯一解释 |
| 地区 | 可修改的浏览范围提示 | Dialect 树与筛选语义 | 不将莆仙父节点自动当作每个子地区的语言事实 |
| 搜索 | 导航入口、地方语境 | Entry 查询与结果页 | 不另建莆仙专用搜索 API |
| 录音 | 邀请文案、已知词条引用 | 录音创建、Speaker / Operator、来源、同意与提交状态 | 来源站点不等于语言背景、授权或当前 GPS |
| 分享 | 兴化语记来源标签及“继续逛”动作 | Entry / Recording 对象链接、公开信息与权限 | 分享直达对象，不强迫绕回首页 |
| 集盒 / 专题 | 地方合集标题、通用对象引用 | Collection 内容及成员关系 | 旧词单不能凭相同数字 ID 变成新 Collection |
| 账户 | 迁移解释与通用入口 | 身份、登录、权限、“我的贡献” | 不创建 Station 专用用户表 |
| 历史资料 | 状态说明、来源与 fallback | 经过审计的映射和可见性 | 未迁移不伪装成已经恢复；原文再发布需权利确认 |

## 3. ProductProfile 最小信息需求

以下是设计字段需求，不是新增数据库 schema 或已实现 API。Language Space 定义资料范围；Distribution Profile 定义品牌呈现，二者分别引用。

| 字段 | 示例 / 要求 | 必需性 |
| --- | --- | --- |
| `slug` / `legacy_namespace` | `hinghwa`；登记的来源命名空间 | 必需；未知值安全降级 |
| `display_name` / `relationship_label` | 兴化语记 / 乡声集盒 · 莆仙方言站 | 必需 |
| `distribution_profile_key` | 建议 `hinghwa-puxian` | 必需；仅作为展示上下文 |
| `language_space_ref` / `dialect_qualified_code` | 由领域负责人确认的空间引用 / 当前 Dialect code `闽.莆仙` | 必需；运行时解析，不硬编码数据库 ID |
| `intro` / `default_scope_label` | 用户说明 / 莆仙方言 | 必需 |
| `featured_refs` | 已发布 Campaign / Entry / Recording / Collection 的类型和引用 | 可空；只能展示当前用户可见内容 |
| `history_links` | 已登记 URL、标题、来源、可用性与权利状态 | 可空；不可接受 query 中任意外部跳转 |
| `capability_state` | 查询、播放、录音各自的可用状态 | 使用通用状态，不由 profile 绕过维护门禁 |

第二地方站只替换这些登记信息、语言空间与精选内容。它仍使用同一套四入口、详情、账户、证据和 URL 解析规则；不复制 `entries` / `recordings` 服务。验收时用“另一地方语言站”中性样例替换品牌和 Dialect，确认页面结构与动作去向无需改变。

## 4. 入口、深链、退出与返回

当前 `frontend/src/pages.json` 未登记 Station 路由。`codex/x4-station-navigation` 的 `ae1c256` 含地方站和上下文实现草稿，但未在本基线合并；本次不 cherry-pick 该分支或将其历史测试记录当作当前验收。

| 用户入口 | 设计目标 | 当前状态 / 返回规则 |
| --- | --- | --- |
| 旧首页 / 兴化语记品牌入口 | `/pages/stations/index?station=hinghwa` | **建议路由，待实现**；目前可落通用 `/pages/index`，说明站点承接尚未完成 |
| 站内查词 | `/pages/search?keywords=<编码词>&station=hinghwa` | 搜索路由和 `keywords` 已有；Station 上下文与地区默认筛选需后续接线 |
| 站内录音 | `/pages/recordings/create`，已知 V2 Entry 时带 `entry_id` | 通用录音页已有；Station 默认地区与回站接线待实现；用户须确认字段 |
| Entry / Recording 分享 | `/pages/entries/details?id=<V2 ID>` / `/pages/recordings/details?id=<V2 ID>` | 路由已有；先验证公开可见性；来源标签与回站待接线 |
| 旧对象链接 | `/pages/stations/legacy?station=hinghwa&namespace=hinghwa&type=entry&legacy_id=<旧 ID>` | **建议承接路由，待实现**；服务端按 #432 的 source key 查询映射 |
| 通用“听 / 我” | `/pages/index` / `/pages/users/me` | 已有；“我”只代表当前登录主体，不由旧 URL 指定用户 |
| 详情返回 | 有栈返回上一页；冷启动提供“继续逛兴化语记” | 真实返回使用页面栈；无有效站点上下文回通用首页；显式继续逛是前进动作 |

建议上下文白名单为登记的 `station` / `profile`、正整数 `dialect_id`、语义 `return_to=station|home`。上下文不能决定对象 ID、授权或证据；不得接受任意 `return_to` URL。旧 ID 不直接作为 V2 `id` 或 `entry_id`。

```text
品牌 / 旧首页 → 地方站 → 查 → Entry → 关联 Recording → 留一句
旧对象分享 → 验证映射与可见性 → 通用详情 → 继续逛地方站
                         ↘ 无映射 / 冲突 → 说明 → 搜索或地方站
四入口“我” → 通用账户 / 我的贡献；从地方站进入不产生另一身份
```

## 5. 状态、文案与降级

| 状态 | 用户文案 / 表现 | 保留动作 |
| --- | --- | --- |
| 加载 | 保留品牌与搜索入口；只对待加载区块显示占位 | 不重复提交；不播放空音频 |
| 暂无公开录音 | “这个范围还没有公开乡音。你愿意留一句吗？” | 查词、录音；录音是否可用服从通用门禁 |
| 词条缺少可靠资料 | “目前资料还不足以可靠回答这个问题。” | 听已有公开录音、按可用能力补充；不生成方言事实 |
| 单区块失败 | “乡音暂时没加载出来，请重试。” | 查词、其他正常内容；局部重试 |
| 录音维护 / 权限拒绝 | 明确原因，不循环申请权限 | 查、听；通用录音页处理恢复路径 |
| 旧链接无映射 / 不公开 | “暂未找到可公开访问的对应资料。” | 自主搜索、回站；不泄漏隐藏对象是否存在 |
| 映射冲突 | “这条旧链接暂不能确定对应资料。” | 自主搜索、回站；不自动打开第一条候选 |
| 未迁移历史能力 | “这项历史内容尚未在这里接入。” | 明确来源与可用性，查词 / 听乡音；不声称数据已迁移 |
| 提交成功 | 通用提交状态及“查看我的贡献” | 回详情 / 继续逛；不把提交成功说成已审核可信 |

## 6. Demo 与验收证据

打开原型 → 识别“兴化语记”及产品关系 → 点击查词进入通用搜索示意 → 返回站点 → 打开真人乡音的通用详情示意 → 录一句 → 查看提交示意。切换“资料不足 / 局部失败 / 旧链接 / 第二地方站”及“深色预览”查看对应设计。原型不调用 API、不录音、不登录、不写入资料；提交仅模拟通用反馈。搜索展示固定 fixture 示例结果，不随输入执行真实检索。

| #428 验收项 | 可 review 证据 |
| --- | --- |
| 老用户识别兴化语记 | 原型首屏品牌、范围与关系说明；用户实测留待实现后的 Demo Gate |
| 不复制领域对象 | 第 2 节边界表、通用详情与账户去向 |
| 地方内容自然进入听 / 查 / 录 | 第 1、4 节及可点击原型 |
| 可复制第二地方站 | 第 3 节字段表、原型第二站模式 |
| IA / 深链 / 原型产物 | 本文、原型 HTML / PNG、[旧 URL 映射](X4_LEGACY_URL_MAPPING.md) |

未验证：真实中老年用户的品牌识别、微信真机、真实音频、上线后的导航和地区筛选、生产入口。它们不属于本设计 Leaf 的实现交付；后续实施仍须独立 Issue 和验收。

实际检查（2026-10-03）：Playwright 打开本地 HTML，执行搜索 → Entry → Recording → 录音提交反馈示意；检查五种设计状态、逐页返回、主动回站、深浅主题切换及第二站的中性内容。360 / 390 / 768 / 900 / 1024 / 1280 / 1500px 宽度均无横向溢出，浏览器无 JavaScript 错误。已查看浅色、深色与 390×844 手机截图确认布局。检查针对设计原型，不代表 H5 产品或微信真机测试通过。

视觉优化独立 agent review：源码与三张截图复核通过，未发现剩余实质问题；确认主题 Token、视图返回栈、第二站内容与示例标注一致，未扩大为运行时产品实现。审查未重复执行上述 Playwright 检查。
