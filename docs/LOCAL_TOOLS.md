# 地方工具资料发布

「地方工具」页按方言限定码加载拼音方案、聪明花开、亲戚计算器。页面里的手动选择优先。打开题集分享时默认使用链接中的方言、题集版本，并从第一题开始。普通入口优先使用个人资料里的主方言，其次用入口给定的方言。词条中的拼音入口使用所选读音的方言。资料按限定码精确匹配，未发布的方言显示缺包提示。

## 编辑与发布

1. 在 Django 后台「地方资料包」建立一个方言、工具组合。方言选择需要方言的查看权限。编辑角色需有对应资料包和资料版本的查看、新增及编辑权限，发布角色另授「可以发布、恢复或下架地方资料」权限。
2. 在「地方资料版本」新增版本。填写标题、适用口音、公开出处和后台权利依据。可以修改资料内容，或上传现成的 JSON。下列三个示例文件可以用作编辑起点。
3. 保存草稿后，用「预览保存的内容」核对口音、例字、题目、答案和出处。草稿只在后台预览。发布角色在版本列表选中一条执行「发布或恢复选中的版本」。已发布版本冻结，修改时新增版本。
4. 选择先前版本执行同一动作即可恢复。执行「下架选中的版本」会撤除该版本；下架当前版本后，整个工具在这个方言下暂不可用，直到重新发布一个版本。题集改版后，旧分享继续定位原题集。撤回带问题的旧题集时，也应对旧版本执行下架。

| 文件 | 内容与边界 |
| --- | --- |
| [pinyin.json](../backend/guantou/localtools/examples/pinyin.json) | 莆田城里口音入门，收录少量声母、韵母、例字及本调。完整旧表、教程文本、视频和录音须查清继承许可。 |
| [quiz.json](../backend/guantou/localtools/examples/quiz.json) | 根据可追溯的音系事实新编三道练习题。旧版真题首发、图片和音频复用仍需确认原授权。 |
| [kinship.json](../backend/guantou/localtools/examples/kinship.json) | 首批有限称谓事实及基础关系图，覆盖若干直系、旁系和姻亲情况。称谓适用范围由地方编辑再核定。 |

运维也可以在 `backend/guantou` 运行 `python manage.py import_local_material localtools/examples/quiz.json`，将文件载入草稿。重复导入相同版本和内容会保留已有记录。部署迁移只建表。

## 资料格式

每个文件的 `payload.schema` 为 1。拼音表的每一行至少提供 `form`。可选 `ipa`、`example`、`entry_id`、`recording_id`。题目依次提供题干 `prompt`、选项 `options`、从 0 开始的正确答案编号 `answer`、解析 `explanation`。亲属关系以 `selfId` 和 `nodes` 表达。每个角色可以带多个 `terms`，分别标注实际用法及公开词条、录音编号。只填写已核对的本系统公开编号。接口每次读取时检查词条和录音的公开状态。

旧版亲属关系引擎按同父同母同胞、两名父母的模型计算。已知当前配偶视为子女的另一位父母。异父母同胞、继亲、义亲和再婚情形暂缺模型支持。测试了基础的长幼分支和祖父的多个儿子，界面会提示候选不完整或现有资料无覆盖。

## 来源与权利

旧 Web AGPL 覆盖合法授权的软件代码，亲戚计算器复用原始确定性引擎。旧 uni-app 记录了莆仙乡音社向原项目授予拼音、例字的项目使用授权。当前示例只整理少量独立事实和原创练习。完整旧资料、旧题集、录音和历史成绩需分别核对、确认和处理。示例不绑定未验的线上词条编号或录音。
