# 双站 H5 分享观察

在聚合日明细按 `site`（站点）、`surface`（对象类型）、`event_name`（动作）、`result`（结果）查看。五类对象是 `collection` 菜单／集盒、`entry` 词条、`recording` 录音、`search` 查词和 `quiz` 题集。浏览器生成的分享链接带一个固定类名，除此之外保留打开内容所需的既有参数。

| 指标 | 计数条件 | 可用分母 |
| --- | --- | --- |
| `share_clipboard / success` | 剪贴板回调成功。回调失败另计 `error`。系统分享失败后回退复制也计入。 | 复制成功和失败回调之和。 |
| `share_system / attempt` | H5 调用系统分享 API。 | 调用量。 |
| `share_system / success` 或 `cancelled` | 浏览器分享 Promise 完成，或返回 `AbortError`。其他拒绝记作 `error`，并回退复制。 | 同组 API 调用量。关闭页面等情况可能缺少最终回调。 |
| `share_opened / success` | 带固定类名的链接冷启动，新文档加载了同目标的公开内容。查词请求成功但无结果也算打开。 | 独立打开量。无法推断接收人数或计算逐链接转化率。 |

发送端 API 调用与接收端打开分别计数。浏览器报告调用完成、链接已复制或出现分享面板，不等于对方收到。打开事件每个文档最多一次，重载页面属于新文档。旧链接、普通站内跳转、缺包、下架或首次加载失败不计成功打开。登录后流水、微信小程序分享、系统级收到次数、设备型号和用户版本需通过受控真机试用补证。

## 配置与汇总

分享计数使用站点 Profile 的 `BOX_PRODUCT_PROFILE_ORIGINS` 配置和同样的匹配规则。Origin 缺失时使用当前请求的方案和 Host。没有发布 Profile 的入口及其他未匹配入口同站点界面一样归入 `general`。正式观察前从两个内测入口各验证一次匿名请求，检查是否归入预期站点。配置方法见[双站产品资料](DUAL_BETA_PRODUCT_PROFILES.md)。

`python manage.py aggregate_product_events` 按部署时区汇总已结束的自然日。在线日仍在写入原始事件。查看后台「产品事件日汇总」的站点、事件、对象和结果列。汇总的 `event_count` 是上报次数，`unique_sessions` 是该分组内不同临时页面会话数。采集失败无法上报，可能由浏览器权限、网络、内容拦截和跨域限制导致。缺少行表示未收到样本，使用双站受控样本检查完整性后再解释计数。

## 隐私

事件体仅包含固定事件名、对象分类、结果、平台和临时页面会话。会话由客户端随机产生，进程内使用，后端按日加盐哈希。请求省略 Cookie、授权令牌和访客编号，引用来源限制为站点 Origin。词、对象编号、方言或题集编号、答案、分数和整条分享链接只用于打开内容及本地验证，均不进入指标。匿名事件沿用现有原始明细保留期与审计排除。

题集页需要在共享版本的资料成功载入后，用与分享时相同的路径调用 `observeSharedOpen`。展开普通工具页、切换到另一方言或者加载不到分享版本时无需调用。发送端通过现有 `sharePage` 自动标记明确指定题集版本的路径。
