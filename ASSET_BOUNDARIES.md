# Asset and Data Boundaries / 资产与数据边界

The root software license governs original software code only where e-dialect
is authorized to grant that license. It does not, merely because a file is
stored in this repository or processed by the application, grant permission
for dictionary content, corpora, recordings, annotations, user uploads, model
weights, generated media/data, personal data, or brand assets.

| Path or material | Boundary |
|---|---|
| Application, test, and material-processing source code authored for this repository | Software license in [`LICENSE`](./LICENSE), subject to authorship and path-level exceptions |
| `backend/guantou/guantou/fixtures/hinghwa_demo.json` | Development fixture data; no additional data/content license is granted by the root software license |
| `tools/materials/dialect_seed/dialects.json` | Dialect seed/reference data; provenance remains documented beside the file, and no additional data/content license is granted by the root software license |
| Files supplied to or generated by `tools/materials/**` | External input/output assets; not licensed by the processing scripts' software license |
| `docs/assets/**` and `frontend/favicon.png` | Documentation screenshots and visual assets; no additional media or brand license is granted unless an adjacent notice says otherwise |
| Runtime databases, uploads, recordings, media, exports, caches, and backups | Operational/user assets; excluded from the repository software license and require their own lawful basis |
| ASR/TTS models, weights, voice samples, and generated audio | Require separate model, data, speaker/voice, and output-rights review |
| `乡声万语`, `乡声集盒`, `兴化语记`, logos, and visual brand assets | No trademark or brand permission is granted by the software license |

Test fixtures must be synthetic or separately authorized. Moving external data
into the repository does not change its ownership or license. A future data or
media contribution must identify source, provenance, consent where relevant,
and an explicit data/asset agreement; the code CLA is not a substitute.
